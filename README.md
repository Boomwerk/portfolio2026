# 🚀 Développeur Web Full-Stack Portfolio

Mon portfolio personnel développé pour présenter mes projets, mes compétences et mon parcours en tant que développeur web Full-Stack.

## ✨ Aperçu

Ce portfolio met en avant :
- 📂 Mes projets personnels et professionnels
- 💼 Mon parcours et mes expériences
- 🛠️ Les technologies que j'utilise
- 📬 Un moyen de me contacter

L'objectif était de créer une interface moderne, fluide et responsive avec des animations discrètes pour améliorer l'expérience utilisateur.

---

## 🛠️ Technologies utilisées

- ⚛️ React
- ⚡ Vite
- 🎨 Tailwind CSS
- 🌼 DaisyUI
- 🎬 Framer Motion
- ✨ AOS (Animate On Scroll)

---

## 🚀 Fonctionnalités

- Design responsive
- Animations au scroll
- Animations fluides avec Framer Motion
- Navigation moderne
- Sections dynamiques
- Code organisé et facilement maintenable

---

## 📦 Installation

Clonez le projet :

```bash
git clone https://github.com/votre-utilisateur/votre-repo.git
```

Accédez au dossier :

```bash
cd votre-repo
```

Installez les dépendances :

```bash
npm install
```

Lancez le serveur de développement :

```bash
npm run dev
```
